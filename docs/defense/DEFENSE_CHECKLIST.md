# Final-year project defense checklist

Demonstrate the complete workflow:

1. Register a student.
2. Verify the account.
3. Log in as a student.
4. Search resources by keyword/course/category.
5. Download a resource and show the download count.
6. Log in as Lecturer and upload a resource up to 100 MB.
7. Log in as Administrator and create/promote/deactivate-style manage accounts.
8. Show the difference between Student, Lecturer and Administrator permissions.
9. Change a password.
10. Demonstrate password reset.

For the written report, make sure screenshots, database/ERD, use-case diagram, sequence diagram, class diagram and architecture diagram describe the same implementation and role names.
